

# Add Unique Contract Record ID and Link Lifecycle to It

## Overview
Add a unique, human-readable identification number (e.g., `ACH-0001`) to every row in `affiliate_contract_history`, auto-generated and globally unique across all affiliates. Then replace `samsaran_pr` with this record ID as the key for lifecycle management routing and checklist association.

## Database Changes

### 1. Add `record_number` column to `affiliate_contract_history`
- Add a `record_number TEXT NOT NULL UNIQUE` column with a default generated via a sequence
- Create a sequence `affiliate_contract_record_seq` and a trigger to auto-assign `ACH-XXXX` format on insert
- Backfill existing rows with sequential IDs

### 2. Add `contract_record_id` column to `affiliate_lifecycle_checklists`
- Add `contract_record_id TEXT` column to reference the record number
- Backfill existing rows by joining on `user_id` + `samsaran_pr` to `affiliate_contract_history.record_number`
- Going forward, checklist items will be keyed by `contract_record_id` instead of `samsaran_pr`

## Frontend Changes

### 1. `src/pages/AffiliateContractHistory.tsx`
- Add `record_number` to the `ContractHistoryRow` interface
- Display `Record #` as the first column in the table
- Change lifecycle link from `/lifecycle/${encodeURIComponent(row.samsaran_pr)}` to `/lifecycle/${row.record_number}`
- Record number is read-only (auto-generated), not in the add/edit form

### 2. `src/App.tsx`
- Change route from `:samsaranPr` to `:recordNumber`: `/admin/affiliate-personnel/:id/lifecycle/:recordNumber`

### 3. `src/pages/AffiliateLifecycle.tsx`
- Read `recordNumber` from params instead of `samsaranPr`
- Fetch contract record by `record_number` instead of `samsaran_pr`
- Display record number in the header
- Pass `recordNumber` to checklist queries and initialization

### 4. `src/pages/AffiliatePersonnel.tsx`
- Update the "Manage Lifecycle" dropdown link to use the latest contract's `record_number` instead of `samsaran_pr`
- Fetch `record_number` alongside existing contract history queries

## Record Number Format
- Pattern: `ACH-0001`, `ACH-0002`, etc. (zero-padded 4 digits, globally unique)
- Auto-generated by a database trigger on insert — no user input needed
